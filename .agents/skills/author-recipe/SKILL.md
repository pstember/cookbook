# Author a recipe

1. Read the [recipe authoring guide](../../../docs/recipe-authoring.md) and the recipe's source or kitchen notes. Record uncertainties that need a source check or a test cook.
2. Ask the user about anything the source leaves open before you write it down. Typical gaps are the yield, the tin or pan size, the oven mode, a missing duration or readiness cue, whether a method choice should stay as options, allergens, and storage times. Ask as the gaps come up, at any point in the work. Do not fill a gap with a guess.
3. Write the ingredient checklist and illustrated method. Break the method into steps of atomic instructions as the guide’s “Write each step” section describes: one stage, one heat setting and one illustration per step, and one action per instruction. Preserve stable step and ingredient IDs when revising content.
4. Build the chart by listing ingredient IDs in each step’s `uses`. Mark the step’s activity, supported duration, heat and waits. Attach each timer to its starting instruction. Preserve qualifiers such as “per batch” or “at least”.
5. Add kitchen notes, ingredient-derived allergens, supported storage guidance and the source. Use a finished yield and ingredient data for any nutrition estimate per 100 g. Leave unsupported values open.
6. Write the second language and both captions for each step’s single 640 × 480 WebP. Check the recipe on screen and in print in English and French. Use the [verify skill](../verify/SKILL.md) before publishing.
