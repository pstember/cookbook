# Author a recipe

1. Read the [recipe authoring guide](../../../docs/recipe-authoring.md) and the recipe's source or kitchen notes. Record uncertainties that need a source check or a test cook.
2. Write the ingredient checklist and illustrated method. Preserve stable step and ingredient IDs when revising content.
3. Add planning facts, useful waits and their start cues. Add an at-a-glance overview when it helps the cook plan the work. Follow the examples in the guide.
4. Write the second language and matching image captions. Use the [verify skill](../verify/SKILL.md) before opening a pull request.
